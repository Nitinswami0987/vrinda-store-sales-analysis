The objective of this project is to analyze sales and order data and present useful information through an interactive Excel dashboard.

## 🛠️ Tools Used

- Microsoft Excel

## 📌 Excel Features Used

- PivotTables
- PivotCharts
- Slicers
- KPI Metrics
- Data Analysis
- Interactive Dashboard

## 📈 Dashboard

The dashboard includes:

- Orders vs Sales
- Sales by Gender
- Order Status Analysis
- Top 5 States by Sales
- Orders by Age and Gender
- Orders by Channel
- Total Sales
- Total Orders
- Total Quantity
- Average Order Value

## 🎛️ Interactive Filters

The dashboard includes slicers for:

- Month
- Channel
- Category

These slicers allow users to filter the dashboard and analyze the data interactively.
